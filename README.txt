NOVA ESTATES — Professional Real Estate Platform
Location: Mahbubnagar, Telangana, India
Tagline: Building Trust. Creating Futures.

HOW TO PREVIEW & RUN:
--------------------
Method 1 (Instant):
Double-click "index.html" in Chrome or Edge to view the main website.
Double-click "admin.html" to access the Admin Dashboard.

Method 2 (Local Server):
Double-click "start-server.bat" (or run ".\serve.ps1" in PowerShell).
The website will open automatically at http://localhost:8080/

KEY FILES:
----------
- index.html: Main corporate real estate website
- property.html: Dedicated individual property detail page
- admin.html: Full Admin Dashboard (Property CRUD & Lead Pipeline)
- data.js: Shared data store & configuration
- app.js: Filters, search, form validation & modals
- admin.js: Admin dashboard logic & CSV export
- style.css: Modern, responsive corporate stylesheet (#2563EB & #142B4E)
- README.md: Comprehensive documentation
